# 猜数字游戏
一个勇Python写的命令行小游戏，支持自定义数字范围和成绩统计。
## 功能
- 自定义数字范围（最小值、最大值）
- 实时提示“太大”或“太小”
- 统计总游戏轮数、平均猜测次数、最佳成绩
- 支持随时输入`q`退出
## 运行方法
1.确保电脑已安装Python 3.x
2.在终端中进入项目目录
3.运行：
```bash
python3 猜数字.py
```
